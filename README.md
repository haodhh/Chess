# Chess

Ứng dụng cờ vua để tự luyện tập, lấy cảm hứng từ Chess.com. Giai đoạn đầu tập trung vào 3 module:

- **Puzzle:** Rated, theo chủ đề, Puzzle Rush, ôn lại lỗi bằng spaced repetition
- **Train:** luyện tọa độ (Vision), chơi với bot, drills tàn cuộc, Game Review
- **Learn:** bài học tương tác theo lộ trình, khai cuộc và repertoire

Xem kế hoạch chi tiết tại [docs/PLAN.md](docs/PLAN.md).
